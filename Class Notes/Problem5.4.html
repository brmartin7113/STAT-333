i.)

Collinearity is defined as one explanatory variable being explained by some linear combination of other variables. A variance inflation factor (VIF) is a standardized method in determining which explanatory variables’ variances effect each other. An explanatory variable with a high VIF is considered to be collinear with the other variables.

ii.)

A large VIF is considered to be any number greater than 10 usually.

iii.)

If some explanatory variable does have a large VIF, it’s not the end of the world. One option to deal with this problem is to scale that variable and repeat the model generation.

iv.)

Seeing that the VIFs for all explanatory variables are way less than 10. I do believe that collinearity is not an issue with this particular fitted model.

i.)

In data analysis, we are using all of the data we have to generate regression models to predict some arbitrary thing. However, there exists some point(s) in the data that does not line up with the rest of the data. These points can leverage the creation of the regression to make the predictions less accurate overall.

ii.)

To find the leverage values, we produce the Hat matrix via \(X(X'X)^{-1}X'\) and take the diagonals from the Hat matrix. To determine which leverage values are too extreme, we check if it is three times greater than the mean of all leverage values. When applying this rule for the current leverage values, we see that points 5, 11, 13, 21, 41, 52, 95, 102, 127, 177, 197, 206, 217, 223, 230, 232, and 257 all have high leverages.

iii.)

If we were to change our predictor from LNFACE to FACE. Then based on our previous leverage values from LNFACE. We can expect the leverage values for FACE to increase by a factor of e.
